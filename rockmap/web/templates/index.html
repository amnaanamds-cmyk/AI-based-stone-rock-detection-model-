Getting started

  1. Add a scene — upload a Sentinel-2 / Landsat GeoTIFF (with an optional SRTM DEM and a reference geological map), or create a synthetic study area to try the system.
  2. Train the CNN, Random Forest and SVM on a scene that has a reference geological map.
  3. Select a region and classify to produce a colour-coded lithological map, area statistics and an accuracy report.
